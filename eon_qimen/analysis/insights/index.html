eon_qimen::analysis

Module insights 

Source
Expand description

Reading of a built plate: void palaces (空亡), the horse star (馬星), formations (格局) and a per-palace auspice score.

The scores are a transparent heuristic over classical tables (see crate::analysis::lore); they rank palaces against each other and are not a prediction.
