Module mcp_tools 

Source
Expand description

MCP tools that wrap the CLI commands one-to-one.

Each tool builds the same command struct the CLI parses from flags, runs its execute and returns the text summary (default) or the full JSON. eon_analyze (the all-engine synthesis) lives in mcp.rs.
